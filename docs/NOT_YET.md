# EH3D-NODE-BUNGARD-AUX: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| A signed update | The update from GitHub checks the SHA-256 that the release publishes and a signing key is still missing | the key exists and the node verifies it |
| A second laser for the tilt of the table | One reading point gives the height; the tilt comes from several measures taken one after another | the first measure is taken on a real table and a person asks for it |
| Recording the video on the node | The node streams and does not store; storing needs a card and a policy for the space | a person asks for it and a board has the card |
| An output that opens by itself on a hot spindle without the control unit | The control unit and the person stop the machine; the node only opens the stop line | the carrier board is built and the owner decides the wiring |
| Closed-loop control of the light from the camera | The ring follows its settings and its timer; the camera and the light do not talk to each other yet | the camera runs on a board |
| A second spindle sensor | One input counts the pulses of the one spindle of the machine | a machine has two spindles |
